# Data layout

`reference/` contains the fixed conservative WENO5 solutions and evaluation subset used for the final two-dimensional Burgers audit. `source/` contains JSON, JSONL, CSV, and NPZ experiment outputs used to compute tables and figures.

Model checkpoints and optimizer states are not tracked in Git. They can be regenerated from the scripts, or distributed separately as release assets with checksums.

The data are numerical simulation and neural-network evaluation outputs generated by this project; they contain no personal or sensitive information.
